# timcardwell.com

Personal site for Tim Cardwell, served by GitHub Pages from `master` at https://www.timcardwell.com.

Plain HTML, CSS and JS with no build step: `index.html`, `styles.css`, `main.js`.

- Preview: `python3 -m http.server 8000`, then open http://localhost:8000
- Update the resume: overwrite `resume.pdf`
- Deploy: push to `master`
